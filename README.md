# 📋 Todo List App

A simple and interactive Todo List application built with **React** as a collaborative group project.  
This project demonstrates core React concepts like state management, props, lifting state up, and component-based architecture.

---

## 🚀 Features

- ➕ Add new todos
- ✅ Mark todos as complete
- 🗑️ Delete todos
- 📊 Display total number of todos
- 🎨 Clean and responsive UI with custom CSS
- 💾 Git collaboration workflow

---

## 🛠️ Tech Stack

- **React** (useState, props, lifting state)
- **CSS3** (custom styling)
- **Git & GitHub** (version control & collaboration)

---
